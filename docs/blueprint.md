# **App Name**: Applaud

## Core Features:

- Recognition Feed: Display a feed of recent recognition events with details like who gave the recognition, who received it, and the reason.
- Recognition Nomination: Enable users to nominate colleagues for recognition based on pre-defined values or custom reasons. Support the inclusion of a personal message with each nomination.
- AI-Powered Recognition Tool: Integrate an AI-powered tool to suggest appropriate recognition reasons or phrases based on keywords provided by the user, enhancing the quality and impact of the recognition.
- Social Engagement: Allow users to react to and comment on recognition posts, fostering a culture of appreciation and engagement.
- Secure Authentication: Implement user authentication and authorization to ensure that only authenticated employees can access the recognition system.
- Login Page (Admin/Boss): Username and password fields for admin/boss login.
- Dashboard: Dashboard with live feed from all cameras (multi-camera view), staff list (recognized with green, unknown with red), and real-time notifications.
- Sign-In/Sign-Out History: List of all recognized staff with timestamps, filterable by staff name, date, and camera.
- Manage Staff: Upload new staff images (JPG/PNG), edit or delete existing staff.
- Notification Settings: Toggle Email/SMS notifications, configure boss email and phone number.
- Camera Settings: List of connected DVR cameras, add new camera (RTSP URL), PTZ control for compatible cameras.

## Style Guidelines:

- Primary color: Soft, welcoming purple (#A381C7) to evoke creativity and trust.
- Background color: Light lavender (#F5EEF8), for a calm, neutral backdrop.
- Accent color: Muted pink (#D6A8B4), analogous to purple, adds warmth.
- Clean, modern fonts to ensure readability.
- Simple, intuitive icons to represent actions and values.
- Card-based layout for recognition posts to organize content.
- Subtle, positive animations to indicate successful recognition submissions or reactions.
